# לוטו · מרכז ניתוח

Site: https://devopsdevopshaim-wq.github.io/lotto/

ניתוח סטטיסטי של תוצאות הלוטו (הפורמט הנוכחי: 37 מספרים + חזק 1–7, מאז מרץ 2011):
שכיחויות ומבחן חי בריבוע, פערים, זוגות ושלישיות, התפלגויות מול התאוריה, בדיקה לאחור של שיטות "חיזוי",
מחולל טפסים ובדיקת טופס מול כל ההיסטוריה.

## עדכון התוצאות

האתר טוען את `lotto.csv` אוטומטית. שלוש דרכים לעדכן:

1. **אוטומטית**: ה־workflow `.github/workflows/update-results.yml` מנסה להוריד את הקובץ ממפעל הפיס אחרי כל הגרלה.
   אם מפעל הפיס חוסם את השרתים של GitHub, הריצה מסתיימת באזהרה ולא משנה כלום. אפשר להריץ אותו ידנית מלשונית Actions.
2. **ידנית בריפו**: להוריד את קובץ התוצאות מ־https://www.pais.co.il/lotto/archive.aspx ולהעלות אותו במקום `lotto.csv`.
3. **בדפדפן בלבד**: לגרור את הקובץ לעמוד. ההגרלות נשמרות בדפדפן, ו"ייצוא CSV" מוריד קובץ מאוחד שאפשר להעלות לריפו.

הקובץ יכול להיות בקידוד Windows‑1255 (כמו שמפעל הפיס מוציא) או UTF‑8.
